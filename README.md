# JJupload

Video-uploadpagina voor Joost en Jenneke's 40-jarig huwelijksfeest. Gasten
vullen hun naam in en uploaden video's, die via een Google Apps Script
backend in een Google Drive-map terechtkomen.

Live: https://pepecsik.github.io/jjupload/

De backend-code (Apps Script) staat niet in deze repo, omdat die de
Drive-map-ID, Sheet-ID en een privé e-mailadres bevat.
